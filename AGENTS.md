# AGENTS.md — working on Echoes of the Last Dawn

Read first: `docs/PROGRESS.md` (state + exact next task), `docs/DECISIONS.md`, `docs/CAMPAIGN.md`, `docs/CONTENT_MANIFEST.md`.

## Ground rules
- Engine is pinned: **Godot 4.4.1-stable**, Compatibility renderer, single-threaded Web. Typed GDScript only. No C#, no native plugins.
- Content lives in `content/*.json` (authoritative). Do not hardcode story in scripts; add events/maps/quests as data.
- Art and audio are generated by `tools/gen_art.py` and `tools/gen_audio.py`. Edit the generators, rerun them, commit the outputs.
- Never ship debug unlocks: harnesses live in `tests/` which is excluded from exports.
- Keep saves backward compatible: bump `GameState.SCHEMA_VERSION` and add a migration step in `Saves.validate_and_migrate`, plus a test.

## Verify before committing
```
python3 tools/validate_content.py
godot --headless --import            # refresh class cache after adding class_name scripts
godot --headless -s res://tools/check_scripts.gd
godot --headless res://tests/test_runner.tscn
godot --headless -- --smoke          # full Prologue → Chapter Three traversal (~1 min)
godot --headless -- --padtest        # gamepad-only drive of every screen (Steam Deck layout)
```
Exports: `tools/build.sh` (runs all of the above, exports Web + Linux, packages).
