# Decisions

| # | Decision | Why |
|---|---|---|
| 1 | Godot **4.4.1-stable**, pinned in project, CI and docs | Mature Compatibility renderer and single-threaded Web export; templates verified locally. |
| 2 | Compatibility renderer everywhere; single-threaded Web (`variant/thread_support=false`) | Same look on WebGL2, Steam Deck and desktop; no COOP/COEP headers needed on itch.io. |
| 3 | Content as validated JSON (`content/`) loaded by one `Content` registry | Easy to author/diff/validate without the editor; one authoritative source per data kind. Maps and events load on demand. |
| 4 | Grid-based field movement with smooth interpolation | Reliable collision/heights/stairs on all inputs; classic JRPG feel; trivially testable reachability. |
| 5 | Maps built procedurally from ASCII rows into a few batched meshes with **baked vertex lighting** | Atmospheric night lighting without dynamic lights; ~5 draw calls per map; deterministic. |
| 6 | Upright Y-billboard sprites stretched by 1/cos(pitch) | Removes foreshortening without sprites leaning into walls; 24 px/unit everywhere. |
| 7 | All art and music generated by local deterministic Python scripts | No paid tools or unclear licenses; fully reproducible. Quality is "coherent original pixel art", not hand-painted; can be replaced asset-by-asset later. |
| 8 | Pixelify Sans (OFL) as the single UI font; glyphs outside it replaced with » « • × * + | Pixel-consistent and licensed; avoids tofu boxes. |
| 9 | Battle simulation separate from presentation; event lists + ack | Headless deterministic tests and balance sims; presentation can never desync rewards. |
| 10 | Status durations count the affected unit's own turns | Statuses never tick during paused menus; easy to explain. |
| 11 | Damage constant 1.5 and enemy stats tuned from sims | Initial 2.2 made fights 4 actions long; sims put common fights at ~8–13 actions and the boss at ~95 at expected level. |
| 12 | Auto-battle never uses items | Spec: avoid automatic rare-item spending. Consequence: bosses expect manual play at the intended level. |
| 13 | KO'd members revive at 1 HP after victory | Avoids post-battle chores and accidental soft progress blocks. |
| 14 | Retry after defeat restores a pre-battle snapshot; "Adjust & retry" opens the menu first | No hidden permanent losses; lets players change party/equipment for bosses. |
| 15 | Saves: temp-write → read-back verify → keep `.bak` → rename; JSON schema v2 with migrations | Never overwrite a good save with a bad one; recover from corruption. |
| 16 | Browser save transfer through download / file picker (JavaScriptBridge); native through `user://exports` / `user://imports` folders | Works without a backend; honest about not being cloud saves. |
| 17 | Code under MIT; original generated assets "all rights reserved" by the project owner until the owner chooses otherwise | We must not invent a license for the owner's art; MIT is a reversible default for code — **owner should confirm**. |
| 18 | JP has no refunds; learned abilities are permanent and job changes are free | Respec without punishment while keeping JP choices meaningful. |
| 19 | Reserve members: 75% XP (×2 catch-up when >2 levels behind), 50% JP | Switching characters never requires recovery grinding. |
| 20 | Garran is the planned mid-game loss (Ch6), Wren comes home without her memories (ending) | Serious loss with lasting consequences; hopeful ending without resurrection. Revisit after Ch2–Ch5 are written. |
| 21 | People are procedural low-poly 3D models (rounded boxes + inverted-hull outline + pixel face decal), built at runtime from `assets/models/appearance.json`, which `tools/gen_art.py` exports from the same palette as the sprites | No external model files or third-party assets; tiny download; consistent identity with portraits; one switch back to pixel sprites in Settings. Enemies stay 2D for now. |
| 22 | Objective locations are derived from data (the event that advances a quest stage and where it can be triggered, following `call` chains; scripted `warp`s count as passages), with an optional per-stage `"target"` override | Story authors never maintain a second set of coordinates; a test guarantees every stage resolves. |
| 23 | Difficulty and random-battle frequency are device settings (Settings), changeable any time; Normal was retuned (+35% XP, Chapter One boss −10% HP) against an explicit natural-progression estimate that a test enforces | No save-schema change; players can drop to Story mid-boss without losing progress. The estimate is conservative and must be replaced by playtest data. |
| 24 | Playtest data is a local-only play report the player exports by hand; no telemetry or network calls | Respects privacy and works offline; still gives the developer real numbers (time per objective, defeats, FPS). |
| 25 | The browser build is an installable PWA (Godot's service worker, cache-first) with an explicit on-title update button | Fullscreen and offline on phones; the update button keeps cache-first from stranding players on old builds. |
